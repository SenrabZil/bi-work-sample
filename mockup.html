Measure & methodology

Visual metadata

Why every tile has one. Two figures should only be compared once their bases match, so each measure states its basis where the reader is looking, not in a separate document. In Power BI these six lines are one row per measure in a measure basis register held in the model, shown through the visual’s info button or a tooltip page, so the text on screen and the documentation cannot drift apart.

Glossary & methodology

Definitions used in this illustrative M2i Power BI work sample

Important: all figures are illustrative rather than M2i production data. Where this mock-up uses a screening rule, weighting choice or migration tolerance, it is labelled as a sample analytical method—not as an established M2i methodology. CRMA percentages shown below are regulatory benchmarks used for demonstration.

Commodity & risk measures

Import reliance — share of apparent consumption supplied by imports. The headline portfolio KPI is volume-weighted so larger commodity flows contribute proportionately.
Portfolio reliance = Σ(reliance % × import volume) ÷ Σ(import volume)
High-dependency / high-risk — illustrative screening rule used in this sample: import reliance >80% and supply risk >3. It is a demonstration threshold, not an asserted M2i standard.
Supply risk — illustrative composite risk score representing vulnerability of supply. Higher values indicate greater risk. In a production implementation, the exact source fields, transformations and scoring methodology would be documented in the semantic model/data catalogue.
Economic importance — illustrative relative importance score used as the second axis of the risk matrix. Higher values indicate greater economic significance.
Import volume — 2025 import quantity expressed in kilotonnes (kt) for commodities in the current filter context.
TTM change — trailing-twelve-month change in the indexed price series; here December 2025 versus January 2025, where January = 100.

CRMA benchmarks

Extraction / processing / recycling — sample tracker against the EU Critical Raw Materials Act 2030 benchmarks shown in this mock-up: 10% extraction, 40% processing and 25% recycling of annual EU consumption.
65% diversification threshold — benchmark used here to flag where more than 65% of EU annual consumption of a strategic raw material at a relevant processing stage is supplied from a single third country.The chart is an analytical monitoring aid; it does not imply that 65% is an operational prohibition or automatic compliance verdict.

Trade concentration

HHI (Herfindahl–Hirschman Index) — concentration measure calculated as the sum of squared supplier market shares. A higher HHI indicates supply concentrated among fewer countries.
HHI = Σ(supplier share × 100)²
This sample marks 2,500 as a concentration reference line for interpretation.
Portfolio HHI — where multiple commodity groups are selected, the displayed HHI is weighted by import value/volume in the sample rather than taking a simple average of group indices.
Net trade — imports less exports for the selected commodity group(s), shown alongside monthly import and export values.

Info buttons and the measure basis register

The i on a tile: opens the basis of that figure in six lines. It answers “what exactly is this a number of?” before anyone compares it with another figure, on this platform or elsewhere.
Measure: what is counted. Method: how it is calculated, including any weighting or threshold. Scope: which commodities, geography and filter context apply. Source: where the data comes from and its tier. Transformation: what was done between source and tile. Freshness: the period covered and when it was last refreshed.
Measure basis register: the table behind the buttons, one row per measure. In Power BI it lives in the semantic model, so the popup text, the documentation and the handover pack are the same rows, maintained once.

Data provenance & access

Derived — metric produced from source data using documented transformations or calculations. Where known, the sample badge also names the underlying source family, e.g. Comext.
Proprietary — information or analytical logic treated as an M2i-owned/intelligence layer in this mock-up.
Restricted-use — data subject to tighter contractual, licensing or role-based access controls. The sample assumes restricted-use tiles do not expose table export.
Viewing as: Internal — illustrative row-level/role-based security context. A production model would map authorised groups/roles to the semantic model.

Data quality & release assurance

Reconciled — dataset has passed its defined comparison/check process with no unresolved break relevant to release.
Held — publication is stopped pending resolution or explicit manual release.
Release gate — all mandatory checks must pass before a dataset is published. The six checks in this work sample demonstrate the control pattern rather than prescribe M2i's production gate.
Open break — unresolved discrepancy between the expected/reference value and the produced dataset.
Refresh target — illustrative service target used to distinguish normal, slow and failed semantic-model refreshes.

Power BI → Fabric migration

Bronze / Silver / Gold — common medallion pattern: Bronze retains landed/raw source data; Silver contains cleaned/conformed transformations; Gold contains business-ready analytical outputs.
Semantic model — governed analytical layer containing relationships, measures, security roles and business definitions consumed by Power BI or other reporting experiences.
Row-level comparison — old/reference and rebuilt outputs are compared at the lowest practical grain before retirement approval. This sample uses commodity-month rows.
Migration tolerance — this sample treats values as matching within 0.01 EUR m. A production tolerance would be agreed per dataset/measure, based on materiality and rounding behaviour.
Retirement rule — the Power BI reference remains live while a material comparison break exists; retirement becomes eligible only once agreed reconciliation evidence is clean.
