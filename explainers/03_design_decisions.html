01

A clean star, with three exceptions

All 53 relationships run many-to-one in a single direction and are always active. Nothing is bidirectional, nothing joins many-to-many, and nothing waits on a switch in DAX. That's the textbook part.

Three places depart from textbook form on purpose. Each one was chosen for a reason, each has a cost, and each is something a production build would revisit.

02

Commodity at two levels

Most sources report by single commodity. Four report only by commodity group: the CRMA benchmarks, concentration, the price index and partner shares. Those four link to the group table directly. Everything else links to the commodity table, which rolls up to its group.

Predict first: a reader picks cobalt in a slicer built on the commodity table. Does the CRMA benchmark figure respond?

Why build it this way? Each source keeps its own grain, so no group figure is split or guessed down to commodity level. The cost is a slicer that can surprise a reader. The production answer: slice on the group table where group figures appear, and label group-level tiles plainly.

03

One country, four meanings

The country table has five relationships, and they don't all mean the same thing. Pick a country and it filters:

ProducerCountry production and reserves
Trade partnerPartner shares of EU trade
Supplier to the EUEU supplier shares
Largest supplierTwo tables name the largest supplier of each commodity

One table keeps the model small and gives the reader one country list. The cost: a single country slicer filters every meaning at once. The production answer is to split it into role tables, one per meaning, so each slicer means one thing.

04

Stage, stored twice

The value-chain coverage table links to the shared stage table. The CRMA benchmark table carries its own stage name and sort order instead, built in Power Query as the benchmark arrives. It's easy to audit against the source, but the names could drift from the shared list. The production answer is a stage key and one more relationship.

None of these was changed for the mock-up. The model's specification is the source of truth, and every change to it has to pass the validator.

05

The rule, in one breath

Keep the star clean, and make every exception a decision you can name.

Mixed grain, a role-playing country table and a duplicated stage all have reasons. What makes them defensible is that each one is written down with its cost and its fix.
